# 🛒 Retail Database & SQL Analysis Project

## 🎯 Objective
Designed and queried a fully normalized relational database (Customers, Products, Orders, Order Items, Payments, and Product Reviews) to extract business insights and analyze customer purchasing behavior[cite: 3, 27].

## 🛠️ Tech Stack & Tools
* **Database Management:** MySQL / MySQL Workbench
* **Querying Concepts:** Joins, Subqueries, Aggregations, Group By, Filtering, and Set Operations.

## 📊 Key SQL Queries & Insights
* **Multi-Table Joins:** Utilized `INNER JOIN` and `LEFT JOIN` to combine customer details with order statuses and payment methods.
* **Aggregations & Grouping:** Calculated total revenue, average order values, and category-wise product distribution.
* **Subqueries:** Implemented inner queries to isolate high-value orders and products priced above the corporate average.
